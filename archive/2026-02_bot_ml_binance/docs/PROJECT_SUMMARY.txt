BACKTESTING BIASES ADDRESSED
================================================================================

1. LOOK-AHEAD BIAS
   Problem: Using current candle's close for entry decisions
   Solution: Use next candle's open price

2. OPTIMIZATION BIAS (CURVE FITTING)
   Problem: Single train-test split vulnerable to overfitting
   Solution: Walk-forward validation with rolling windows

3. SLIPPAGE
   Problem: Backtest assumes perfect execution
   Solution: Model 0.05% average slippage

4. DATA LEAKAGE
   Problem: Indicators use future data
   Solution: Proper indicator lagging

5. SURVIVORSHIP BIAS
   Problem: Only testing on current coins
   Solution: Test on multiple coins, historical data
